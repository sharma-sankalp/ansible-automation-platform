# Ansible Overview

## Overview

Ansible is an open-source automation platform used for configuration management, application deployment, infrastructure provisioning, and operational automation.

It uses an agentless architecture, communicating with managed hosts over SSH (or WinRM for Windows).

## Key Features

- Agentless automation
- YAML-based playbooks
- Idempotent execution
- Reusable roles
- Secure secret management
- Multi-platform support
